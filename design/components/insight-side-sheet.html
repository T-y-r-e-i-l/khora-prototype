States

  • .body.insights-closed — column width → 0; .ins-collapse stays visible on the edge.
  • aside.insights.ref-open — hides head and lists; shows reference panel.
  • ≤900px — sheet is a full-bleed overlay via .body.show-insights; seg becomes .seg-select.
  • Hidden entirely in market / quests modes.

Composed primitives

  • Segmented control — Insights / Readings / Beliefs
  • Progress — score ring + bars
  • Chip — category filters
  • Insight card — list rows
  • Tooltip — criteria / chip hover copy (.read-tip)
