Components

FAB

Phone navigation (≤900px): the desktop sidenav collapses into a bottom-right floating action button. Open state fans destinations in a 2–3–1 cluster.

Documented

Interactive preview — tap the FAB

When it appears

  • Viewport ≤ 900px — desktop keeps the icon rail.
  • Pinned bottom-right with safe-area inset; z-index --z-fab (90).
  • Closed: 64px toggle + floating .nav-new above it.
  • Open: html.fab-open + .nav-fab-scrim; destinations stagger into a 2–3–1 fan.

Class contract

Class / stateRole
.nav-fab-toggle64px circular open/close control
.nav-fab-menu / .nav-fab-closeIcon swap inside the toggle
.nav-fab-scrimDim + blur behind the fan (z 85)
html.fab-openOpens cluster; hides standalone New
html.nav-hiddenHides the whole FAB chrome
nav.sidenav .nav-itemSame items as desktop; absolute + transform when open
